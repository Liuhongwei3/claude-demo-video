- 下载导入模板：原片只有鼠标悬停「下载订单产品导入模板」，没有点击下载；成片只标注入口，不展示下载过程。
- 工艺卡片「自动创建」：原片没有下达前的工艺卡片页面作对比，只能证明下达后存在对应记录。
- 品牌：原片没有出现产品名称或 Logo，成片用纯文字收尾。
