## 设计思路

- 叙事闭环：生产工单 → 工序链路 → 工序任务 → 插入新工序（流程演进）→ 新工序任务出现在执行人员的个人工作台 → 负责人在派发管理中分派任务 → 回到演进后的 6 道工序链路收束。镜头 4 里出现的「Z26-0218 首检 / 段差磨」正是镜头 3 刚插入的工序，前后形成真实的业务呼应。
- 竖屏构图：没有把整张桌面画面缩小塞进竖屏，而是用程序化的「虚拟镜头」，对每个镜头独立做裁切、缩放和平移。主体 UI 放在宽 960 px 的圆角卡片里，常用放大倍数 1.45–2.45。表格类画面先给全景交代上下文，再推近到重点字段。工序链路先完整入画，再推近局部。
- 版式：上方是步骤标签和主标题，中间是真实界面卡片，下方是旁白字幕，三者互不重叠，字幕不会盖住按钮、字段或工序名称。
- 动效：只用缓动推拉、聚焦描边、轻度聚光、点击涟漪（只放在原片真实点击的时间和位置上），以及 0.15–0.3 秒的交叉淡化。不使用抖动、旋转或弹跳。
- 主色：取自产品界面，侧栏深蓝 `#2f3f55`，主题蓝 `#1e88f3`。素材中没有明确的 Logo，所以没有虚构品牌标识，结尾用纯文字。
- 声音：普通话男声旁白；背景音乐是程序合成的简约科技风（100 BPM，IV–V–iii–vi 和声，最后解决到 Cmaj9）；只在开场、链路出现、点击、新增成功、页面切换和收尾处放轻微提示音。配音时音乐自动压低约 9 dB。整体响度 −16 LUFS，峰值 −4.3 dBFS。

## 质检结果（已实际检查成片）

- 编码与规格：经 ffprobe 确认为 1080×1920、30/1 fps、H.264 High、AAC 48 kHz，时长 28.800 s，可完整播放。
- 配音清晰度：用离线语音识别（SenseVoice）分别识别单句配音和混音后的成片音轨，6 句全部与文案一致。只有个别同音字的写法不同（如「报工 / 曝工」「工单 / 公单」），读音相同。
- 字幕：逐帧检查，没有错字和溢出。最长单行 18 字，字号 44 px，放在半透明底框内，21 字以上的句子在逗号处分成两行。
- 构图：每 0.5 秒抽帧检查一次，没有露出浏览器栏、任务栏、水印或背后的列表页，也没有加载骨架屏或白屏。
- 业务真实性：没有任何伪造的成功提示。「新增成功」是原片真实画面；报工和批量派发都没有展示结果。

## 未完成 / 需要补充的素材

1. **任务报工操作（功能三）**：原片在个人工作台没有展开「操作 ▾」菜单，看不到「报工」按钮或报工弹窗。成片只高亮了操作列并标注「任务操作入口」，「直接报工」只由旁白讲述。**建议补录约 3 秒**：在个人任务管理中点开某个任务的操作 ▾ → 报工 → 填写数量并确认。
2. **批量派发操作（功能四）**：原片有勾选列、「已选中 N 项」，以及派发表单中的「添加派发」（一次提交多条派发），但没有「勾选多条任务 → 点击批量派发」的完整操作，也没有派发成功的结果。**建议补录约 3 秒**。
3. **删除工序**：原片打开了「取消目标任务」确认框，但点了「返回」，没有实际删除，所以成片只用「插入工序」来证明流程可以灵活调整。
4. **画质**：B 站未登录状态下最高只能拿到 720P（视频码率约 226 kbps）。放大 2 倍以上时，小字号略有发软。原片是 4K 录制，提供账号 Cookie 中的 `SESSDATA` 后可以重新拉取高清源，一条命令重新渲染（见 README），所有镜头坐标会自动适配。
5. **配音**：当前环境访问微软 Edge 在线 TTS 返回 403，而且其商用授权也不明确，所以改用离线开源模型 Kokoro v1.1-zh（Apache-2.0，经语音识别评测从 45 个男声中选出 68 号）。自然度不如真人或商业 TTS。正式投放前建议用真人配音替换：按 `voiceover-script.txt` 的时间码录制 6 句，覆盖 `build/vo/line_00.wav … line_05.wav`，再执行 `python3 project/audio.py`，最后只需重新封装，不用重新渲染画面。
6. **品牌信息**：素材中没有 Logo 或明确的产品名（浏览器标签只显示「生产工单管理 - 云…」，被截断）。如需加上品牌收尾，请提供 Logo 和产品名称，可以在 `project/script.py` 的收尾文案中加入。

## 使用的工具

- FFmpeg 6：原片解码、H.264 / AAC 编码、封装
- Python 3.12：OpenCV（裁切、缩放、合成）、Pillow（中文排版）、NumPy / SciPy（音乐与音效合成、混音）、pyloudnorm（响度标准化）
- sherpa-onnx：Kokoro v1.1-zh 离线中文 TTS（Apache-2.0）、SenseVoice 离线语音识别（配音质检）
- 字体：思源黑体 Noto Sans CJK SC（SIL OFL 1.1）
- 原片获取：`tools/fetch_bilibili.py`（B 站公开 WBI 接口）

## 素材与授权

- 产品界面只使用了提供的原片，没有补录，也没有登录或修改任何业务系统数据。
- 背景音乐和音效全部由代码合成（`project/audio.py`），没有第三方音频。
- TTS 模型使用 Apache-2.0 授权，字体使用 SIL OFL 1.1 授权，均可商用。
